## このセッションで実装した範囲

詳細は `docs/changelog.md` の 2026-05-23 セクション参照。要点のみ：

### 1. ウォッチャー機能（新規）
- `pc/gui/pc_watcher.py`: データモデル + 評価 (image_appear / image_gone / ocr_number)
- `pc/gui/pc_watcher_editor.py`: 編集ウィンドウ（単発テスト・連続監視テスト・OCR debug 画像保存）
- 一覧で **チェックボックス** 即トグル、handler/after 設定 UI

### 2. シーンステップ拡張（mobile 同等）
- `call_scene` / `if_image` / `keyevent` / `scroll` / `group_header` / `pick_scene` を `pc_scene.py` に実装
- 循環参照ガード `_MAX_CALL_DEPTH=10`
- シーン編集 UI から追加できるよう「+ その他のステップ ▾」メニュー追加

### 3. フロー連動
- `PcFlowRunner` にウォッチャー統合（バックグラウンドポーリング → 発火キュー → handler 実行 → after 動作）
- after = `noop` / `restart_scene` / `next_scene` / `stop`
- 連続ヒット (`consecutive`) と冷却 (`cooldown_s`) を管理

### 4. フロー編集ウィンドウ（新規）
- `pc/gui/pc_flow_editor.py`: 7 曜日 × 48 時刻スロット (30 分刻み) のテーブル
- **現在時刻に赤線**（1 秒ごと更新）+ **今日の曜日列を薄黄ハイライト**
- セルダブルクリックで新規/編集ダイアログ
- 日付跨ぎ対応（QTimer）

### 5. メイン実行タブを曜日ページャー化
- `◀ ▶ 今日` ボタンで曜日切替、当日のエントリのみ表示
- 起動したまま日付が変わると自動で次の曜日に追従

### 6. UI 日本語化
- シーン編集のステップタイプ表示・メニュー・ダイアログタイトルを日本語に
- JSON 内部の type 名は英語のまま（互換性維持）

### 7. ログ統合とローテーション
- `pc/gui/logger.py`: `write_log` / `purge_old_logs`
- フロー実行・ウォッチャー発火・経験値メーターが `logs/YYYY-MM-DD.log` に集約
- 起動時に 30 日より古いログを削除（`settings.log_retain_days` で調整可）

### 8. OCR 改善
- `pc_main.py` で起動時に Tesseract パスを設定（`run_pc_flow.py` 経由でも OCR が動くように）
- `ocr_number` で PSM 7/8/6 を試行し最長数字列を採用

## 環境メモ

- Nightcrows ウィンドウタイトル: 設定済み（`pc/settings.json` の `window_title`）
- Pico マウス: COM ポート自動検出
- Tesseract: `C:\Program Files\Tesseract-OCR\tesseract.exe` で自動検出される想定
- TeamViewer 経由での運用: マウス操作・オーバーレイは動く、Touch Injection はリモートセッション制限で不可

## 既知の制約（運用時に注意）

- **テンプレマッチはサイズ依存**: シーン作成時と実行時で Nightcrows ウィンドウサイズを揃える（A 運用で当面様子見）
  - 必要になったら撮影時サイズを JSON に記録してリサイズマッチ（B 案）を実装
- Pico HID 必須: Nightcrows のチート対策で `SendInput` クリックは弾かれる
- マウス加速 ON だと `move_to` 精度が落ちる。HID 移動の最遅 25 px/s で運用
