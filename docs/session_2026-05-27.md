## 主要な実装内容

### 1. PC 版に `_last_due_scenes` フォールバックを移植 (`pc/gui/pc_flow.py`)

mobile 版にあった「シーン外でウォッチャー発火 + `after=restart_scene` 時に当日直近スケジュールへ戻る」仕組みを `last_due_scenes()` として PC 版にも実装。深夜跨ぎや起動直後の発火に対応。

### 2. 短距離マウス移動の精度改善 (`pc/pico_mouse.py`)

エピック-テネリス海峡シーンの 26 番目で位置ズレが指摘されたが、ログ確認で HID 誤差は ±1〜2px と判明（実際の問題は後述 #4）。それでも HID 精度改善は実施：

- `_SHORT_MOVE_THRESHOLD_PX=80` / `_SHORT_MOVE_STEP=5` / `_SHORT_MOVE_DELAY=0.04` を定数化
- `click_at` で距離 ≤80px なら精度優先パラメータに自動切替
- `move_to` の HID 単位ゼロ丸めを ±1 に補正（speed_scale > 1.0 での収束保証）

### 3. snapshot / wait_image ステップを分離

ユーザー指摘で **「スクショ撮影マーカー」と「画像出現待ち」は別物にすべき**となった：

- `snapshot` ステップ → スクショ撮影マーカー専用 (`{"path": "snapshots/..."}` のみ)、再生時 no-op
- `wait_image` ステップ → 新規追加、`{"template": "templates/...", "threshold", "timeout_s", "region"}` でテンプレマッチ待機
- 旧形式の自動マイグレーション: `load_pc_scene` で「snapshot + templates/ 配下 path」を `wait_image` に変換、「snapshot + snapshots/ 配下 path」は撮影マーカーとしてパラメータ簡素化
- 編集 UI: キャンバス左ドラッグ「画像出現待ち」が `wait_image` を生成、ステップ表示は「📷 スクショ撮影」「⏳ 画像出現待ち」に区別

### 4. テネリス海峡シーン 26 番目のズレ原因 (ユーザー側で要再作成)

実際の原因は HID 精度ではなく、ステップ 25 が `snapshots/` 配下を path に持つ snapshot で **再生時スキップされて wait できていなかった**こと。新仕様で `wait_image` を使うように作り直せば解決する見込み。

### 5. フロー全体編集の 05:10 DQ 削除問題 (`pc/gui/pc_flow_editor.py`)

`_find_entry_at` が `entry.time == time_str` の完全一致を要求していたため、05:10 のような中途半端な時刻のエントリが見つからず削除/編集不可だった。「同じ 30 分スロットに収まる時刻」マッチに変更（`_time_to_row` ベース判定）。seq エントリも除外。

### 6. 実行タブのダブルクリック編集 (`pc/gui/pc_main.py`)

メイン実行タブのスケジュールテーブル（24 時間 × 1 列）に `cellDoubleClicked` を接続。表示中曜日と時刻 HH 部分に合致する非 seq エントリを集めて、単一なら `_EntryDialog`、複数なら選択メニュー → 編集 → `save_pc_flow` + ランナーへ即時反映。`_EntryDialog` は QTimeEdit で **1 分単位の時刻指定** に対応。

### 7. 対象ウィンドウ前面化機能

- **判定ヘルパー** (`pc_flow.py`): `is_window_foreground()` / `bring_window_to_foreground()`。後者は `SwitchToThisWindow` を使用。**合成入力でなく API 呼び出しなので Nightcrows のチート対策に弾かれない**（実機検証済み）。
- **確認ダイアログ** (新規 `pc/gui/foreground_dialog.py`): 「▶ 即時実施 / ⏸ 3 分待機 / ⊘ スキップ」の 3 ボタン + 30 秒カウントダウン。タイムアウトで自動「即時実施」（人がいないと判断）。
- **PcFlowRunner 組込**: シーン実行直前（`_run_scenes_with_watcher` + `_handle_fired` 両方）で前面チェック → 非前面なら確認ダイアログ要求シグナル発火。
- **キャッシュ機構**: `foreground_check_interval_min`（既定 5 分）で「直近の選択 (run/skip) を N 分キャッシュして自動適用」。ウォッチャーが秒単位で連続発火しても毎回ダイアログが出ない。`wait` はキャッシュ対象外。
- **設定 UI**: 設定ダイアログに `QDoubleSpinBox`（0〜120 分）追加。

### 8. フロー実行中オーバーレイ (新規 `pc/gui/flow_overlay.py`)

経験値メーターと同じ作り（`FramelessWindowHint + WindowStaysOnTopHint`）で半透明バーをゲームウィンドウに重ねて表示：
- 1 行目: 現在シーン名 + ステップ進捗
- 2 行目: 次回スケジュール
- 3 行目: 直近のウォッチャー発火（発生時のみ）
- 左ドラッグで移動、位置を `settings.json` に自動保存
- `⏸` ボタンでフロー停止、`✕` で表示のみ消去
- 設定 `flow_overlay_enabled` (既定 True) で ON/OFF
- フロー開始で自動表示、停止で自動非表示
