## 主要な実装内容

### 1. 短距離 click_at に detour 経由方式を導入 (`pc/pico_mouse.py`)

**動機:** ローカル単独でも短距離タップ (距離 ≤ 80px) で視覚的にクリックがズレる事象。GetCursorPos ベースの誤差は ±2-3 px に収まっていたが、HID 加速の建ち上がり不足 / 終端の沈み込みと推定。

**修正:**
- `_SHORT_MOVE_DETOUR_OFFSET_PX = 300` を追加
- `PicoMouse.__init__`: `self.short_move_detour = True` 既定 ON
- `click_at` の短距離分岐で、`target ± 300px` の detour 位置へ一旦ジャンプしてから target へ長距離アプローチで戻す
- 旧挙動は `mouse.short_move_detour = False` で復活可

**検証:** ユーザー実機で「位置のズレが無い」と確認 (2026-05-29)。詳細は `docs/pc_pico_mouse.md`「`click_at()` の短距離 detour 経由化」セクション。

**TeamViewer 経由のズレ対策として一旦入れた `_settle_before_click` は revert 済み。** ローカルでも副作用が出たため、原因究明を優先する方針。

### 2. ウォッチャー発火→ハンドラー完了の自動録画 (`pc/gui/pc_flow.py`, `recorder.py`, `pc_main.py`)

- `WindowRecorder.start(..., prefix="rec")` に `prefix` 引数を追加。`rec_watcher_<title>_*.mp4` で手動録画と区別
- `PcFlowRunner.set_recorder(recorder, fps)` で pc_main 側の WindowRecorder を共有
- `_handle_fired` の `_run_scene(handler)` 前後で自動 start/stop
- 手動録画中は自動録画スキップ（既存セッションを尊重）
- 録画タブの FPS スピン変更が自動録画にも反映

### 3. `last_due_scenes` に昨日フォールバックを追加 (`pc/gui/pc_flow.py`)

5/28 03:33 死亡ウォッチャー発火が「直近スケジュールが見つからずスキップ」となった事象の対策。`_due_scenes_on(flow, target_date, max_hm_exclusive)` ヘルパーを切出し、今日 → 昨日の 2 段階探索に拡張。詳細は `docs/flow_design.md`「昨日フォールバック」セクション。

### 4. シーン編集「選択行を実行」を複数選択対応 (`pc/gui/pc_scene_editor.py`)

`_list_steps` を `ExtendedSelection` に変更。Ctrl/Shift クリックで複数行選択 → 「選択行を実行」で昇順連続実行。`_launch_thread` に `rows: list[int]` 引数追加で非連続選択でも正しくハイライト。DEL キーで複数行削除対応。

### 5. `if_image` ステップに then/else インライン手順を追加 (`pc/gui/pc_scene.py`, `pc/gui/if_image_dialog.py` 新規, `pc/gui/pc_scene_editor.py`)

**スキーマ:** if_image の params に `then` / `else` (list[dict]) を追加。非空ならその場で `_dict_to_pc_step` で PcStep に変換し、一時 PcScene として再帰実行 (`depth+1`)。空または未指定なら従来の `then_scene` / `else_scene` (シーン名) にフォールバック。

**編集 UI:** 新規 `IfImageEditDialog`。成立時 / 不成立時 それぞれで「インライン手順 / シーン呼出 / 何もしない」を切替。インライン手順は QListWidget で追加・編集・並べ替え・削除。インラインで使えるステップ: `tap` / `wait_fixed` / `keyevent` / `call_scene`。

**追加エントリポイント:**「+ その他のステップ ▾」メニューに「画像で分岐 追加」を新設。「ドラッグで作る (推奨)」案内 or「既存テンプレ画像を選ぶ」（ファイル選択）→ IfImageEditDialog 起動。

### 6. フロー側 GUI に経験値計測タブを追加 (`pc/gui/pc_main.py`)

独立アプリ (`run_exp_meter.py`) の機能をフロー制御アプリ側にも組込。録画タブと翻訳タブの間に「経験値」タブを追加。

- import 済だった `ExpMeter` を実体化、`self._exp_overlay` も保持
- 計測領域 (RegionPickerDialog 起動) / 桁数ヒント / 計測間隔の設定
- 現在値 / 現在速度 / 平均速度 / LvUP 予測 / 計測時間 表示
- 「▶ 計測開始」「🔄 リセット」「🗕 ゲーム画面に重ねる」
- オーバーレイは独立アプリと同じ `OverlayWindow` を `ExpOverlayWindow` として再利用、位置は `overlay_pos` で永続化
- 状態は `exp_meter.json` で永続化（独立アプリとデータ共有）

### 7. LvUP 予測に絶対時刻を併記 (`pc/gui/pc_main.py`, `pc/gui/overlay.py`)

ETA (分) から「現在 + ETA」を計算して絶対時刻 (HH:MM、日跨ぎなら MM/DD HH:MM) を併記。

- 経験値タブ: 「1h30m（現在 → 15:30）  /  2h00m（平均 → 16:00）」
- オーバーレイ: 「残 1h30m → 15:30」（`_lbl_eta` 幅 95 → 155 px に拡張）

### 8. 手動スクショ撮影時に自分側ウィンドウを退避 (`pc/gui/capture_clean.py` 新規, `pc_scene_editor.py`, `pc_watcher_editor.py`, `region_picker.py`)

**動機:** 1 画面運用で編集ウィンドウ等が対象ゲームに重なっていると、DirectX 系では PrintWindow が空で画面 BitBlt フォールバック → 自分側 GUI が映り込む。

**修正:** `capture_window_clean(hwnd, settle_s=0.15)` を新設。撮影中だけ `QApplication.topLevelWidgets()` の可視 widget を `(-30000, -30000)` へ move、150ms 待ってから `capture_window` を呼び、finally で元位置に復帰。

**適用先:** scene/watcher editor の `_capture_snapshot` と `RegionPickerDialog._capture`。**ポーリング系 (ウォッチャー監視・経験値 OCR・録画) は毎回ちらつくため対象外。**

### 9. tap_image / wait_image の値編集ダイアログを追加 (`pc/gui/image_step_dialog.py` 新規, `pc_scene_editor.py`)

**動機:** tap_image で「テンプレ＝region 同サイズ」だとマッチ不可。閾値や探索領域の調整、テンプレ差替を全て JSON 編集なしで完結させたい。さらに「どの画像をどこで探すか」の対応関係を視覚的に明確化したい。

**ダイアログ構成:**
- 「探したい画像 (テンプレート)」: パス + プレビュー + サイズ + **「テンプレを変更…」ボタン**（ゲーム画面キャプチャ → `RegionPickerDialog` で範囲ドラッグ → 切出して `templates/<シーン名>/tpl_<ts>.png` に保存して差替）
- 「検出条件」: 一致閾値 / タイムアウト
- 「探す場所」: X/Y/W/H スピン or「領域なし」チェック + **「範囲を画像で選択…」ボタン**（同じく RegionPickerDialog で範囲指定 → スピンに自動入力）
- 「テスト: 現在のゲーム画面で試す」: 押すと `capture_window_clean` → 現在の設定で `matchTemplate` → 一致 ✓ score / 不一致 best score / 「探索領域がテンプレより小さい」警告 等を表示、緑/赤の枠つきプレビュー
- 「クリック位置オフセット」(tap_image のみ): テンプレ中心からの ±500 px

scene editor の `_edit_step_params` ハンドラに `tap_image` / `wait_image` を登録。呼出側は `step.type, step.params, self._scene.window_title, self` を渡す。`collect()` で `template` も含めて返すので、テンプレ差替もそのまま保存される。
